TECHNICAL Q&A

核心技術 Q&A

FR 科技在網頁性能上與傳統外包有何不同？
傳統外包多使用模板或 WordPress，這會導致代碼冗餘。我們堅持使用純代碼開發，並進行 Code Splitting 與 Tree Shaking 優化，確保 Lighthouse 性能指標達到 95 分以上，提升 300% 以上的載入效能。
你們如何應對大規模流量衝擊 (DDoS)？
我們在雲端架構中整合了三層防護機制：最外層是流量清洗中心，中層為 Web 應用防火牆 (WAF)，內層則透過 Kubernetes 進行動態 Pod 伸縮，能在攻擊發生時自動分流並隔離異常來源。
雲端伺服器的數據備援機制為何？
我們採用「異地多活」備援策略。所有數據每小時進行增量備份，並存儲於獨立的高可用物件存儲中，確保在任何硬體故障的情況下，均能在 15 分鐘內完成全系統災難復原 (Disaster Recovery)。
關於 AI 整合，支持哪些模型協議？
FR 科技支持包含 OpenAI API、Anthropic Claude、以及私有化的 Llama 3 部署。我們能根據業務需求，在伺服器端搭建專屬的向量資料庫 (Vector Database)，實現高效的 RAG (檢索增強生成) 應用。
